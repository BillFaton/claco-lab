\subsection*{3.1 Step response}

1. Plotting the step response. The MATLAB script assumes $G(s) = \frac{1}{(s + 1)(0.5s + 1)} = \frac{1}{s + 1} \frac{1}{0.5s + 1}$ and $G_c(s) = \frac{-s + c}{c(s + 1)(0.5s + 1)} = \frac{-s + c}{c} \frac{1}{s + 1}\frac{1}{0.5s + 1}$.
